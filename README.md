# BO:IM

**안 보이던 기업을 데이터로 증명합니다.**

BO:IM(보임)은 뉴스·특허·채용 정보가 적어 외부에 잘 드러나지 않는 B2B 제조기업의 실제 성장을, 거래명세서 같은 내부 문서를 함께 분석해 증명하는 기업 성장 진단 서비스입니다.

🔗 **[Live Demo](https://boim-hazel.vercel.app)**

---

## 왜 필요한가

기존 신용평가·기업 조회 서비스는 뉴스, 특허, 채용공고 같은 **공개 정보**를 중심으로 기업을 평가합니다. 그런데 실제로는:

- 언론 노출이 없어도 거래처가 꾸준히 늘고 있는 기업
- 특허·채용공고가 적어도 반복 거래로 안정적인 매출을 내는 기업

처럼, **외부에는 안 보이지만 내부적으로는 성장하고 있는 기업**이 적지 않습니다. BO:IM은 공개 데이터(외부 가시성)와 기업이 직접 제공하는 내부 거래 문서(성장 신호)를 함께 분석해서, 공개 정보만으로는 놓치는 성장을 데이터로 보여줍니다.

> 본 서비스는 신용평가가 아닌 AI 기반 성장 진단 참고 자료입니다.

## 진단 과정

| STEP | 화면 | 내용 |
| --- | --- | --- |
| 1 | 기업 검색 | 진단할 기업명을 정확히 입력해 검색 |
| 2 | 외부 가시성 확인 | 뉴스·특허·채용공고 기반 공개 정보 수준 확인 |
| 3 | 내부 문서 업로드 | 거래명세서·세금계산서·발주서 등 6종 문서 업로드 |
| 3.5 | 분석 진행 | 업로드한 문서를 순서대로 분석 (시연용 합성 진행) |
| 4 | AI 분석 결과 확인 | 신뢰도가 낮은 항목만 사용자가 직접 확인·수정 |
| 5 | 성장 신호 · 비교 | 거래처 증가율·재구매율 등 내부 신호를 외부 가시성과 비교 |
| 6 | 성장 리포트 | 종합 진단 결과를 리포트로 확인·인쇄 |

## 기술 스택

- **Framework**: Next.js 16 (App Router, Turbopack)
- **Language**: TypeScript
- **Styling**: Tailwind CSS 4
- **Hosting**: Vercel

프론트엔드 페이지와 API가 하나의 Next.js 앱에서 함께 서빙되며, 서버 컴포넌트는 API를 다시 호출하지 않고 `lib/engine.ts`의 데이터 계층을 직접 사용합니다.

## 프로젝트 구조

```
app/
├── page.tsx                 첫 화면 (서비스 소개)
├── company/                 STEP 1 · 기업 검색
├── visibility/               STEP 2 · 외부 가시성
├── upload/                   STEP 3 · 내부 문서 업로드
├── processing/                STEP 3.5 · 분석 진행
├── review/                   STEP 4 · AI 분석 결과 확인
├── signals/                  STEP 5 · 내부 성장 신호
├── compare/                  STEP 5 · 외부/내부 비교
├── share/                    STEP 6 · 성장 리포트
└── api/
    ├── health/               서버 상태 확인
    ├── companies/            기업 검색 (정확 일치)
    ├── visibility/            외부 가시성 점수
    └── signals/               내부 성장 신호 계산

lib/
├── engine.ts                 API 라우트와 서버 컴포넌트가 공유하는 데이터 계층
├── api.ts                    클라이언트 컴포넌트용 API 클라이언트
├── signals.ts                성장 신호 계산 로직
└── cors.ts                   외부 소비자를 위한 CORS 헤더

data/                         합성(가상) 기업·거래·문서 카테고리 데이터
types/                        공용 타입 정의
```

## API

| Endpoint | 설명 |
| --- | --- |
| `GET /api/health` | 서버 상태 확인 |
| `GET /api/companies?q={기업명}` | 기업명과 정확히 일치하는 기업 검색 |
| `GET /api/visibility` | 뉴스·특허·채용공고 기반 외부 가시성 점수 |
| `GET /api/signals` | 거래처 증가율·재구매율·거래처 집중도 등 내부 성장 신호 |

외부 소비자를 위해 CORS가 열려 있어 다른 프로젝트에서도 호출할 수 있습니다.

## 로컬 실행

```bash
npm install
npm run dev
```

`http://localhost:3000`에서 확인할 수 있습니다.

```bash
npm run build   # 프로덕션 빌드
npm run lint    # 린트 검사
```

## 배포

Vercel에 연동되어 `main` 브랜치에 머지되면 자동 배포됩니다.
