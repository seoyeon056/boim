## D12 - 외부 / 내부 비교

기존

단순 수치 비교

변경

외부 가시성 의미 추가

- 뉴스 0건 → 언론 노출 부족
- 특허 2건 → 공개 기술 흔적 일부 확인
- 채용공고 0건 → 공개 채용 활동 없음
- 가시성 점수 20점 → 외부 정보 부족

내부 성장 신호는

긍정 / 주의

상태를 구분하여 표시
